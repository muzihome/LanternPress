# LanternPress 主题

一款经典报纸复古风 Typecho 主题，基于 LanternTown 二次开发。内置文章点赞、阅读量统计、目录树、模态框搜索、跟随系统主题色、归档 / 友链 / 标签云三大独立页面模板，支持瀑布流加载、图片灯箱、代码高亮复制。性能上实现懒加载、内容缓存、数据库优化；安全上配备 CSP、HSTS、XSS 防护与接口速率限制。适配 PHP 8 与 Typecho 1.3.0+，全站响应式布局。

## 功能特性

### 🎨 视觉设计与主题
- **经典报纸复古风格**：米黄纸张纹理背景，复古排版，营造沉浸式阅读氛围
- **5 种主题色**：复古黄 / 纯白色 / 灰白色 / 暗夜黑 / 跟随系统，一键切换
- **跟随系统深色模式**：自动根据浏览器/系统深色偏好切换明暗主题，matchMedia 监听器自动清理
- **首页图片灰白模式**：支持灰白/彩色两种显示模式，可全局切换
- **全站响应式布局**：适配桌面、平板、手机等多种设备
- **移动端导航统一**：搜索按钮与菜单项风格一致，下拉面板体验流畅

### 📖 文章阅读体验
- **段首自动缩进**：文章正文段首自动缩进 2 个字符，符合中文排版习惯
- **阅读进度条**：文章页顶部显示阅读进度，实时掌握阅读位置
- **阅读时长估算**：根据字数自动估算阅读时长（按 400 字/分钟计算）
- **字数统计**：文章页显示全文字数
- **图片灯箱**：Fancybox 实现，点击放大查看，支持画廊模式，已在链接内的图片不重复包裹
- **代码高亮**：Prism.js 实现，支持行号显示、一键复制、语言标签
- **图片懒加载**：原生 `loading="lazy"` + IntersectionObserver 单例双重保障，避免重复创建 observer
- **无缩略图占位**：文章无缩略图时显示复古渐变背景，避免空白

### 👍 文章交互功能
- **文章点赞**：AJAX 无刷新点赞，Cookie 防重复（1 年内不可重复），IP 速率限制（10 秒 5 次）防刷
- **阅读量统计**：Cookie 防刷（24 小时内同一文章只计一次），SQL 原子递增避免竞态条件
- **文章目录树**：可按文章单独开启/关闭，自动提取标题层级，小屏幕自动隐藏，移动端浮动按钮唤出
- **上下篇导航**：复合条件排序（时间戳 + 文章 ID），避免时间戳相同时漏篇
- **文章分享**：支持复制链接、微博分享，一键操作
- **打赏功能**：支持微信/支付宝二维码打赏，可配置最多 2 张二维码
- **社交媒体链接**：支持微信/微博/GitHub/知乎/B站等多种社交链接，支持二维码和 URL 两种形式
- **作者简介**：文章页底部显示作者头像、昵称、自我介绍、社交链接
- **版权声明**：文章结尾自动显示版权信息，支持 CC BY-NC-SA 4.0 协议

### 🏠 首页与导航
- **推荐文章轮播**：Swiper 实现，支持自定义推荐文章 ID，自动轮播 + 手动切换
- **最新文章列表**：支持缩略图、摘要、阅读量、点赞数，卡片式布局
- **两种翻页模式**：页码翻页 / 瀑布流加载更多（AJAX 无刷新，15 秒超时保护）
- **自定义导航菜单**：支持 `名称|URL` 格式，每行一个，留空自动显示独立页面
- **模态框搜索**：点击「搜索」居中弹出搜索框，输入框与按钮主题色统一，支持 ESC 关闭
- **返回顶部**：平滑滚动按钮，滚动时自动显示/隐藏

### 💬 评论系统
- **AJAX 无刷新提交**：事件委托模式，DOM 替换后无需重新绑定，避免内存泄漏
- **嵌套评论**：支持多级嵌套回复，评论者头像、昵称、时间清晰展示
- **头像镜像代理**：支持 Gravatar 及自定义镜像地址（如 cravatar.cn），解决国内访问慢的问题
- **表单智能填充**：autocomplete 属性，浏览器自动填充姓名/邮箱/网址
- **评论 XSS 防护**：评论内容统一 HTML 转义，防止存储型 XSS
- **评论待审核提示**：待审核评论显示「审核后可见」提示

### 📄 独立页面模板
- **归档页**：按年份/月份归档所有文章，带文章数量统计，数据文件缓存（1 小时 TTL），文章发布时自动清除
- **友链页**：展示友情链接，支持 `名称||地址||简介` 格式自动渲染，也支持自定义 HTML 结构
- **标签云**：展示所有文章标签，按使用频次显示不同大小，点击跳转到对应标签的文章列表

### ⚡ 性能优化
- **SQL 原子递增**：阅读量/点赞使用 `INSERT ... ON DUPLICATE KEY UPDATE int_value = int_value + 1`，避免高并发竞态条件
- **文章内容缓存**：文章内容处理结果数据库缓存，配置哈希校验，配置变更自动失效，长文章性能提升明显
- **请求内字段缓存**：数据库字段操作请求内静态缓存，避免同一请求内重复查询
- **单条 SQL upsert**：字段写入使用 `INSERT ... ON DUPLICATE KEY UPDATE`，替代原 SELECT + INSERT/UPDATE 两次查询
- **批量查询优化**：推荐文章单次内容查询 + 单次字段查询，替代逐项 Archive Widget
- **归档页文件缓存**：归档数据文件缓存，1 小时有效期，文章发布/修改时自动清除
- **IntersectionObserver 单例**：图片懒加载使用单例 observer，避免瀑布流加载更多后重复创建导致内存泄漏
- **SVG 图标静态缓存**：14 个 SVG 图标数组静态缓存，避免每次调用重复构建
- **资源预加载**：preload / preconnect，加速关键资源加载
- **AJAX 片段请求**：瀑布流加载更多只请求文章列表片段，减少整页流量
- **fetch 请求超时**：15 秒 AbortController 超时控制，避免网络异常时按钮一直 loading
- **资源版本号**：CSS/JS 资源统一版本号，便于缓存刷新

### 🔒 安全加固
- **安全响应头**：CSP / X-Frame-Options / X-Content-Type-Options / Referrer-Policy，全方位防护
- **HSTS**：HTTPS 站点自动启用 Strict-Transport-Security，强制 HTTPS 访问
- **点赞接口速率限制**：IP 速率限制（10 秒内最多 5 次），flock 文件锁避免并发竞态
- **可信代理白名单**：IP 获取支持 `LT_TRUSTED_PROXY_IPS` 常量配置，防止客户端伪造 IP 绕过速率限制
- **全局 XSS 防护**：所有 HTML 输出统一转义（`lt_esc_html` / `lt_esc_attr`），JS 变量使用 `json_encode` + JSON_HEX 系列标志
- **URL 安全校验**：`lt_safe_url` 协议白名单（http/https/mailto），防止 javascript: / data: 协议注入
- **缓存目录保护**：`.htaccess` 禁止直接访问，缓存文件前缀 `<?php exit; ?>` 防止直接执行
- **防刷 Cookie httponly**：阅读量/点赞防刷 Cookie 设置 httponly，防止 JS 读取/修改
- **CSRF 防护**：评论表单内置 Typecho Security token，防止跨站请求伪造

### ⚙️ 后台配置与扩展
- **20 个后台配置项**：覆盖基础设置、显示设置、备案设置、高级设置，可视化配置
- **自定义 CSS/JS**：后台直接填写，无需修改主题文件，支持覆盖主题样式和添加交互脚本
- **统计代码注入**：支持百度统计、Google Analytics 等，直接粘贴统计代码即可
- **双备案显示**：ICP 备案号 + 公安备案号（自动链接至 beian.mps.gov.cn），合规展示
- **自定义页脚文案**：可自定义页脚第一行内容，留空显示默认版权信息

- **文章自定义字段**：支持文章摘要、文章主图、目录树开关 3 个自定义字段

### 📱 移动端适配
- **响应式布局**：全站响应式，适配桌面、平板、手机
- **移动端菜单**：点击链接后自动关闭菜单，目录树浮动按钮，搜索模态框

### 🌐 其他特性

## 安装方法

### 方法一：直接上传（推荐）
1. 下载主题压缩包
2. 解压后将 `LanternPress` 文件夹上传到 Typecho 主题目录 `usr/themes/`
3. 登录 Typecho 后台 → 外观 → 启用「LanternPress」主题
4. 点击「设置外观」进行主题配置

### 方法二：Git 克隆
```bash
cd /path/to/usr/themes/
# GitHub（主仓库）
git clone https://github.com/muzihome/LanternPress.git
# Gitee（国内备用，访问更快）
git clone https://gitee.com/muzinext/LanternPress.git
```

### 目录权限
确保缓存目录可写：
```bash
chmod 755 usr/themes/LanternPress/cache
```

## 常见问题

### Q：点赞功能点击无反应？
A：检查以下几点：
1. 确保主题已启用且 functions.php 已正确加载
2. 检查浏览器控制台是否有 JS 报错
3. 确认 `cache` 目录可写（速率限制需要写入缓存）
4. 同一文章 1 年内只能点赞一次（Cookie 限制），清除 Cookie 后可重新点赞
5. 点赞接口有 IP 速率限制（10 秒内最多 5 次），频繁点击会被限流

### Q：归档页不更新？
A：归档页使用文件缓存，文章发布/修改/删除时会自动清除缓存。如手动修改了数据库，可删除 `usr/themes/LanternPress/cache/archive-cache.php` 文件手动清除。

### Q：Gravatar 头像加载慢？
A：在主题配置中填写「头像镜像地址」，推荐使用：
- `https://cravatar.cn/avatar/`
- `https://gravatar.loli.net/avatar/`
- `https://cdn.v2ex.com/gravatar/`

### Q：如何添加友链？
A：创建独立页面，选择「友链页」模板，在页面内容中按以下格式填写：
```markdown
- [站点名称](https://example.com) - 站点描述
- [另一个站点](https://example2.com) - 另一个描述
```

### Q：自定义导航菜单如何配置？
A：在主题配置的「自定义导航菜单」中，每行填写一个菜单项，格式为 `名称|URL`：
```
首页|/
归档|/archives.html
关于|/about.html
谷歌|https://google.com
```
留空则自动显示所有已发布的独立页面。

### Q：瀑布流「加载更多」不工作？
A：检查以下几点：
1. 确认翻页模式设置为「加载更多」
2. 检查浏览器控制台是否有 JS 报错
3. 确认服务器支持 AJAX 请求（返回 `from=ajax` 参数时只输出文章列表片段）
4. 网络异常时请求 15 秒超时，按钮会显示「请求超时，请重试」

### Q：文章内容修改后页面没有更新？
A：文章内容处理结果使用数据库缓存，配置哈希校验。文章发布/修改时会自动清除缓存。如主题配置变更（如关闭 fancybox），缓存会自动失效（配置哈希不匹配），首次访问时重新生成。

### Q：如何配置可信代理白名单？
A：在 Typecho `config.inc.php` 中添加：
```php
define('LT_TRUSTED_PROXY_IPS', ['127.0.0.1', '代理服务器IP']);
```
定义后，仅信任来自这些代理 IP 的 `X-Forwarded-For` / `X-Real-IP` 头，防止客户端伪造 IP 绕过点赞速率限制。未定义时保持向后兼容（信任所有转发头）。

### Q：如何升级主题？
A：备份当前主题目录 → 覆盖新版本文件 → 登录后台 → 外观 → 禁用后重新启用主题 → 检查配置项是否完整 → 清除 OPcache。
